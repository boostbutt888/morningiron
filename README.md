# Morning Iron

A single-page home strength companion for a 06:30–07:15 morning session.

## Equipment
- 5kg + 10kg weighted vests
- 8kg + 12kg kettlebells
- 2 × 10kg dumbbells
- No bench, floor only

## Weekly plan
| Day | Session |
|-----|---------|
| Mon | Push: chest, shoulders |
| Tue | Pull: back, lats, rear delts |
| Wed | Rest / mobility |
| Thu | Push |
| Fri | Pull |
| Sat | Optional legs + core |
| Sun | Rest |

## Features
1. Opens on today's session automatically.
2. Tap a set to log it and start the rest timer (60 / 75 / 90s), with beeps and vibration at zero.
3. Hold timers for planks and hollow holds.
4. **(i)** on each exercise shows target muscles and a start → end drawing.
5. Session clock against the 45-minute target, plus a weekly completion tracker.
6. Keeps the screen awake during a session.

Progress is stored in the browser's localStorage, so it stays on one device.

## Run it
Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from `main`, root) to use it from your phone.
