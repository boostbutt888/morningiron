Progression rules
  1. Use a rep range. When every set hits the top of the range with good form, make it harder next session.
  2. Make it harder in this order: slower 3-sec lowering → 2-sec pause → add vest (5kg → 10kg → 15kg) → heavier kettlebell.
  3. Stop each set 1–2 reps before failure. Form breaks = set ends.
  4. Next purchases, in priority order: doorway pull-up bar + resistance band (lats), then 16kg and 20kg kettlebells.
  5. Do Zwift after strength or in the evening, never right before it.
Recovery & fuel
  1. Protein: 130g/day (1.6g × 80kg). Breakfast at 07:30: 30–40g.
  2. Eat at maintenance or a slight surplus to add size. A deficit stalls muscle gain.
  3. 07:15–08:00: shower, eat, 10 quiet minutes before work.
  4. Sore joints for more than 48 hours: drop the load 20% for a week.
